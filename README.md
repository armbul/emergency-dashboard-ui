# emergency-dashboard-ui

Static emergency-dashboard prototype with an independent, trainable ML research subproject.

## Projects

- Dashboard prototype: open `index.html` locally.
- [Incident ML](ml/incident_classifier/README.md): a CPU-friendly neural text classifier, training and evaluation CLI, synthetic dataset, tests, and development roadmap.

Incident ML is a research demonstration. It is not connected to dashboard workflows or dispatch services. See its model card for limitations and intended use.
